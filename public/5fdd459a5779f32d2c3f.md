# 該当の部分

```
Set-Alias touch New-Item
```

仕組みは簡単でSet-Aliasでコマンドを書き換えてるだけです。

ちなみに
```
Set-Alias <変更後のコマンド> <変更前のコマンド>
```

で好きなコマンドを設定できます
